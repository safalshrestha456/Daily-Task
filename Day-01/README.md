# Day 01: Full Stack Overview, Git Setup & Learning Goals

## 🎯 Day 1 Overview & Objectives

Welcome to **Day 1** of the 2-Month Full Stack Developer Internship!  
Today's objective is to build a solid foundational understanding of the web architecture, contrast frontend and backend responsibilities, understand HTTP networking, JSON formatting, compare REST with GraphQL, and establish a professional Git/GitHub workflow.

---

## 📑 Topics Covered

1. **Full Stack Architecture Overview**
   - Client-Server Architecture
   - Separation of Concerns: Presentation Layer vs Application/Data Layer
2. **Frontend vs Backend Responsibilities**
   - Frontend: UI/UX, DOM, State Management, Client Routing, Responsive Design
   - Backend: Business Logic, Database interactions, Authentication/Authorization, APIs, Security
3. **HTTP Protocol & Communication**
   - Request-Response Lifecycle
   - HTTP Methods: `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS`
   - HTTP Status Codes: `2xx` (Success), `3xx` (Redirection), `4xx` (Client Errors), `5xx` (Server Errors)
   - Headers, Body, Query Parameters, Path Parameters
4. **JSON (JavaScript Object Notation)**
   - Syntax rules, data types (string, number, boolean, array, object, null)
   - Serialization (`JSON.stringify()`) and Deserialization (`JSON.parse()`)
5. **REST vs GraphQL Architecture**
   - Over-fetching vs Under-fetching problems in REST
   - Single endpoint vs multiple endpoints
   - Schema-driven development with GraphQL queries, mutations, and resolvers
6. **Git Version Control & Daily Workflow**
   - Repository initialization, staging, commits, branch management, and remote pushing

## 🛠️ Git Daily Workflow Guide

```bash
# 1. Check current status
git status

# 2. Stage new or modified files
git add <filename>   # or: git add .

# 3. Commit with semantic, descriptive message
git commit -m "Day XX: <Description of task accomplished>"

# 4. Push updates to GitHub remote
git push origin main
```
