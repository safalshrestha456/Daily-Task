# Day 03: CSS Selectors, Box Model, Typography, Display & Positioning

## 🎯 Day 3 Overview & Objectives

In **Day 3**, the focus shifts from structural HTML to presentation styling. The objective is to style the portfolio page using foundational and modern CSS principles:
- **CSS Selectors** (element, class, ID, child, sibling, attribute, pseudo-classes, and pseudo-elements)
- **The CSS Box Model** (`box-sizing: border-box`, margins, borders, padding, content box)
- **Typography** (font hierarchies, line-height, letter-spacing, text decoration)
- **Display Properties** (`block`, `inline`, `inline-block`, `none`)
- **Positioning Schemes** (`static`, `relative`, `absolute`, `fixed`, `sticky`)

---

## 🎨 Implemented Features & Technical Highlights

1. **Sticky Navigation Bar (`position: sticky`):** Stays anchored to the top of the viewport when scrolling, with backdrop blur effects.
2. **Profile & Status Badge (`position: relative` & `position: absolute`):** A live online status indicator anchored to the bottom right of the circular avatar.
3. **Floating Back-to-Top Button (`position: fixed`):** Fixed to the bottom-right corner of the browser viewport.
4. **Box Model Precision (`box-sizing: border-box`):** Applied globally via universal selector to ensure reliable sizing across cards, tables, and form inputs.
5. **Interactive Form States (`:focus`, `:hover`):** Distinct focus rings and transition animations on buttons, text inputs, selects, and textareas.
6. **Zebra-Striped Data Table (`:nth-child(even)`):** Enhanced readability for the 8-week internship schedule.
