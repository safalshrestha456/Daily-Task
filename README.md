# 40-Day Full Stack Developer Internship 🚀

Welcome to my daily progress repository for the **2-Month Full Stack Developer Internship**. This repository tracks daily hands-on assignments, projects, code implementations, and documentation following the curriculum and guidelines provided by my intern tutor.

---

## 📌 Internship Overview

- **Role:** Full Stack Developer Intern
- **Duration:** 2 Months / 8 Weeks / 40 Working Days
- **Daily Schedule:** 7 Hours 5 Minutes learning & practical work
- **Tech Stack:**
  - **Frontend:** React, Vite, Tailwind CSS, Apollo Client, React Router
  - **Backend:** Python, FastAPI, GraphQL, PostgreSQL, SQLAlchemy ORM, JWT
  - **DevOps & Tools:** Git & GitHub, Linux, Docker, Docker Compose, Postman
- **Final Project:** Full Stack Task Management System (React + Apollo Client + FastAPI + GraphQL + PostgreSQL + Docker)
