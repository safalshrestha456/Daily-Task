# Day 02: HTML Structure, Semantic Tags, Forms, Tables & Images

## 🎯 Day 2 Overview & Objectives

In **Day 2**, the objective is to build a structured, semantic, and accessible **Personal Portfolio Page** using pure HTML5 without relying on styling frameworks. This reinforces proper document outlining, accessible document architecture, complex form controls, data tables, and media embedding.

---

## 📑 Core Concepts Covered

1. **HTML5 Semantic Architecture**
   - `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
   - Accessibility benefits of landmarks for assistive tech (screen readers)
2. **Text Formatting & Hierarchies**
   - Headings `<h1>` to `<h3>`, paragraphs `<p>`, `<strong>`, `<em>`, `<blockquote>`
3. **Data Tables**
   - `<table>`, `<thead>`, `<tbody>`, `<tfoot>`, `<tr>`, `<th>`, `<td>`
   - Attributes: `scope="col"`, `colspan`, `rowspan`
4. **Interactive Forms & Controls**
   - `<form>`, `<fieldset>`, `<legend>`, `<label for="...">`
   - Text inputs, emails, phone numbers, select dropdowns with `<optgroup>`
   - Radio buttons, checkboxes, file uploaders, `<textarea>`
   - Form submission and reset buttons
5. **Media & Hyperlinks**
   - SVG vector graphics, `<figure>`, `<figcaption>`
   - Relative internal navigation anchors (`#about`, `#contact`)
   - External links with `target="_blank"` and `rel="noopener noreferrer"`
